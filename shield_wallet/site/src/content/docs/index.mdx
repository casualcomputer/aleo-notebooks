Shield is a self-custodial browser wallet for [Aleo](https://aleo.org), the zero-knowledge L1. This site turns the wallet's user surface and dApp integration behavior into a clean, searchable reference that can stand on its own as a dedicated docs site.

## What makes Shield distinct

<div class="feature-strip">
  <div class="feature">
    <h4>Privacy is a wallet mode</h4>
    <p>Shield treats Aleo's public and private balance model as a normal wallet experience instead of a specialist workflow.</p>
  </div>
  <div class="feature">
    <h4>Proving is configurable</h4>
    <p>Users choose delegated proving for speed or local proving under <code>Settings → Security → Proving mode</code>.</p>
  </div>
  <div class="feature">
    <h4>Docs are split by audience</h4>
    <p>Users get plain-language wallet help. Developers get adapter behavior, integration patterns, and clearly qualified gaps.</p>
  </div>
</div>

## Deploy later without drama

The site is already Vercel-shaped. When you are ready, deploy the `site/` folder as an Astro project. The build command is `npm run build`, the output directory is `dist`, and the production URL should replace the placeholder in `astro.config.mjs` so the sitemap and canonical URLs point at the real domain.
